# Discount Eligibility Checker
- A program that decides if a person is eligible for a discount.

# How to run
- Answer/input your answers to the questions
- The program will show you your eligibility.

# Input needed
- student - if you are a student
- age - your age
- membership - if you have a membership or not

# Example input:
- "Are you a student? Yes or No: Yes"
- "How old are you?: 13"
- "Do you have a membership? Yes or No: Yes"

# Sample output
- "You are eligible for the discount."
